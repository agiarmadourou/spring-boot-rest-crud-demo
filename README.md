# Spring Boot REST CRUD Demo

Course project for practicing Spring Boot REST CRUD APIs.

The project was first implemented with a manual DAO layer using JPA EntityManager, 
and then refactored to use Spring Data JPA.

Technologies:
- Java
- Spring Boot
- Spring Data JPA
- JPA / Hibernate
- MySQL
- Maven

The final version uses a layered backend structure with REST controller, service, 
and repository layers.
